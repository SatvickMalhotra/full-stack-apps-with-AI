A lightweight **furniture catalog + ordering app for clinics**, with a separate admin panel to manage products. Built as zero-build HTML/JS wired to Firebase — open and run, no toolchain.

## ✨ Features

- 🪑 Browse + order clinic furniture (`index.html`)
- 🔐 Admin panel to manage the catalog (`admin.html`)
- ☁️ Firebase-backed data (`firebase.js`, `data.js`)

## 🚀 Run it locally

```bash
cd "Furniture_App"

# Add your Firebase config in firebase.js, then just open:
start index.html        # customer view  (Windows)
start admin.html        # admin view
# macOS: use `open` instead of `start`
```

> Tip: serve with VS Code **Live Server** so Firebase auth domains resolve cleanly.
