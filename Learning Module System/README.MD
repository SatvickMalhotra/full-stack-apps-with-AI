A lean **Learning Management System** — admins build training modules + quizzes, learners take courses and track their progress. Pure HTML/JS, no build step.

## ✨ Features

- 🧑‍🏫 **Admin panel** (`admin.html`) — create modules, quizzes, blogs
- 🎓 **Learner view** (`customer.html`) — take courses, track progress
- 🔐 **Auth** (`auth.js`) — role-based access (admin vs learner)
- 📝 **Quizzes** (`test.html`) — assessments with scoring
- 📰 **Blogs** (`blogs.html`) — supporting training content

## 🚀 Run it locally

```bash
cd "Learning Module System"

# Open the relevant entry point in your browser
start index.html        # login / landing
start admin.html        # build courses
start customer.html     # take courses
# macOS: replace `start` with `open`
```

> Use VS Code **Live Server** for the smoothest experience (auth + storage behave better over http).
