Data entry by **voice** — because we speak faster than we type. Stop typing forms; just talk, and the data entry happens automatically.

## ✨ Why it exists

- 🎙 **Speak, don't type** — voice → structured fields
- ⚡ **~100× faster** for repetitive data entry
- 🧏 **Hands-free** — great for high-volume operational work
- 🌐 Runs in the browser via the Web Speech API — no install

## 🚀 Run it locally

```bash
cd "Voice-Data_Entry_App"

start index.html        # Windows
open index.html         # macOS
```

> Use Chrome/Edge + allow microphone access when prompted (Web Speech API). VS Code **Live Server** recommended for mic permissions over http.
