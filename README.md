## <picture><img src="https://media.giphy.com/media/iY8CRBdQXODJSCERIr/giphy.gif" width="28" /></picture> &nbsp; What's this?

A growing collection of **18 full-stack apps** that I've built **entirely with AI assistance** — Claude, Cursor, ChatGPT, v0, and a handful of other tools. Each folder is a standalone project with its own code, its own stack, its own story.

> **The point isn't the code — it's the velocity.**
> Most of these went from idea to working app in **2–5 days**. I describe what I want, AI writes 90% of the code, I review and ship. This is what product building looks like in 2026.

```yaml
this_repo:
  type:        Workspace · public scratchpad
  purpose:     Showcase what AI can build in a day, a weekend, a week
  apps:        18 (and growing)
  approach:    Prompt → review → iterate → ship
  built_with:  Claude · Cursor · v0 · ChatGPT · Lovable · Bolt
  philosophy:  Code is the means · the user problem is the point
```

## <picture><img src="https://media.giphy.com/media/3oz8xRD2BUbyOG3CXm/giphy.gif" width="30" /></picture> &nbsp; The Vibe-Coding Loop

```
┌──────────────────────────────────────────────────────────────────────┐
│                                                                      │
│   PROMPT          →  describe what you want                          │
│   GENERATE        →  Claude / Cursor writes the code                 │
│   REVIEW          →  read it · catch the dumb stuff                  │
│   ITERATE         →  "do X instead" · "split this file"              │
│   AUTOMATE        →  n8n wires the unsexy parts                      │
│   SHIP            →  Vercel · Supabase · live URL                    │
│   LEARN           →  what worked · what didn't · feed back in        │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

> Most of these apps went from **idea → live URL in 2–5 days**.
> Some are toys, some are real internal tools used at work. All are real working code.

## <picture><img src="https://media.giphy.com/media/LnQjpWaON8nhr21vNW/giphy.gif" width="30" /></picture> &nbsp; Run any app locally

```bash
# 1. Clone the whole repo
git clone https://github.com/SatvickMalhotra/full-stack-apps-with-AI.git
cd full-stack-apps-with-AI

# 2. Pick an app
cd "MediTrack System"     # or any folder

# 3. Check that app's own README for setup
cat README.md
```

Each project ships with its own README, dependencies, and run instructions.
