Effortlessly **schedule, rate, and track job interviews** — no server, no database, works offline. A single self-contained HTML app.

## ✨ Features

- 🗓 **One-click scheduling** — pick date (DD-MM-YYYY) + interview type
- 👤 **Candidate profile** — name, LinkedIn, phone, email, resume link
- 🔔 **Smart reminders** — browser alerts before interviews
- ⭐ **Rating & feedback** — score candidates, add quick notes
- 🕘 **Instant history** — sortable filters over past interviews
- 💯 **100% client-side** — pure HTML/CSS/JS, offline-capable

## 🚀 Run it

```bash
cd "Recruiting_Scheduling_Software"

# Just double-click the latest version, e.g.:
start "HR interview tracker v4.html"   # Windows
open  "HR interview tracker v4.html"   # macOS
```

That's it — the app launches in your browser. No install, no build.
