## 🤖 What it is

Working with **one** ChatGPT is powerful — but sometimes you wish you had *several* working together, challenging each other, and refining the answer until it's genuinely good.

This app lets you run **multiple GPT agents in parallel**. They iterate, critique each other's output, and keep improving **autonomously** until they converge on a single solution. Don't like the result? Tell them to make it better — and they will.

<br />

## ✨ Features

- 🧠 **Multi-agent collaboration** — several GPTs work the same problem at once
- 🔁 **Self-improvement loop** — agents critique and refine until consensus
- 🎯 **Goal-driven** — set the target, the agents converge on it
- 💬 **Human in the loop** — not happy? ask for another pass

<br />

## 🚀 Run it locally

```bash
# 1. Open the folder
cd "AI_Agents(Coding)"

# 2. Just open index.html in your browser
#    (or use VS Code Live Server for hot reload)
start index.html        # Windows
open index.html         # macOS
```

> Add your API key inside `script.js` where indicated, then set the goal and watch the agents work.
